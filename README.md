# Modern Multirole Training Campaign

A dynamic **modern air combat training campaign for DCS World**, designed for both single-player and multiplayer training.

The mission provides multiple modern aircraft, dynamic BVR engagements, campaign-based enemy configurations and a dedicated Free Training environment.

## Main Features

* Dynamic BVR training system
* Multiplayer support
* Dynamic Slots at Kobuleti
* Dedicated airborne **BVR ZONE**
* 16 airborne client slots at approximately 20,000 ft
* Dynamic enemy spawning relative to the requesting player
* Single and Pair enemy spawning
* Randomized 1, 2 or 4 aircraft engagements
* Multiple modern REDFOR and BLUFOR aircraft
* Campaign-based BVR scenarios
* Free Training mode
* F10 radio menu control
* Dedicated mission briefing
* Integrated kneeboard documentation

## Player Aircraft

### BVR ZONE

The dedicated airborne training area contains 16 client slots:

* 4× F-16C
* 4× F/A-18C
* 4× JF-17
* 4× J-11A

All aircraft start airborne at approximately **20,000 ft**.

These slots are independent from the **Dynamic Slots at Kobuleti**.

## Dynamic BVR Spawn System

Enemy aircraft do not spawn from a fixed location.

When a player requests a BVR engagement, the enemy group is dynamically generated **ahead of that specific player**, following the player's current flight direction.

This allows multiple players to use the training environment while maintaining correctly positioned BVR engagements.

## Free Training

Free Training provides access to:

* MiG-29S
* Su-27
* Su-30
* MiG-31
* F-15C
* F-16C
* F/A-18C
* JF-17
* J-11A

Each aircraft type can be generated as:

* Single
* Pair
* Random ×1
* Random ×2
* Random ×4

This allows pilots to create anything from controlled 1v1 engagements to larger BVR scenarios.
